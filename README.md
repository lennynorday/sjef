# Sjef

Goedkoop en simpel koken, met een gedeelde voorraad, boodschappenlijst en eigen recepten.

- Statische web-app (GitHub Pages), te installeren op je beginscherm.
- Gedeelde gegevens staan in Supabase, per huiscode. Zie `supabase.sql`.
- Supabase-adres en publieke sleutel staan in `config.js`.
